## 0. オープニング — 定義と用語の確認（10:00〜10:10 / 10分）

- **冒頭に土台を1枚**（詳細: [07_gakuryoku_definition.md](07_gakuryoku_definition.md)）:

> 学力とは、教育という意図的な働きかけによって**個人の内部に形成**され、外部の道具や他者の即時的支援を欠いた状態でも、**未知の課題に対して自力で呼び出し・組み替え・適用できる、構造化された**知識・技能・思考様式の体系であり、その形成の成否について教育の側が**説明責任**を負いうる能力である。

- 今日効いてくるのは3点だけ口頭で:
  1. **内部保存性**(第2条項): 生徒+AIの複合系が良い成果物を出せるとき、学校が形成したものは何か。AIに委譲してよい部分/委譲したら空洞化する部分の境界線はここから引く
  2. **転移**(第3条項): 学び=転移できる構造の理解。既知問題の再生は記憶であって学力ではない
  3. **標本と本体**(測定): テスト得点も振り返りの理解度も「標本」。固定指標は必ずグッドハート化する — 今日のデータ分析はKPI作りではない
- **用語の確認を1枚**（詳細: [04_tankyu_definitions.md](04_tankyu_definitions.md)）:
  - 小・中の指導要領用語は「**探究的な学習**」=物事の本質を探って見極めようとする一連の知的営み。高校の「探究」はそこに「**自己との関わりで**」が加わる(発達の連続体)。「探究的な学び」は定義のない政策上の上位語 — 定義を問われたら指導要領用語で答える
  - **研究は「世界にとって新しい」ことが要件。探究は「その子にとって新しい」ことで成立する**。学校探究の公式設計は「研究の型で行い、学びの深まりで評価する」(解説理数編: 新たな知見の有無や価値よりも**過程における生徒の思考や態度**を重視)
  - だから後半の「問いみがき」は「研究の型」の練習であり、評価するのは問いの深まり — 成果物の見栄えではない
- 問いかけ: 「先生方の学校には、すでに学習データ(=標本)が眠っています。どこに？」（振り返りシート・小テスト・フォーム回答・成果物）
- 今日の宣言: 生成AIは**答えの出力機ではなく、概念の演算装置**。前半はデータの演算、後半は問いの演算に使う。

## 1. 学習データ分析 — AIに①〜④を任せ、教師は⑤に還る（10:10〜10:45 / 35分）

### 視点の型「5つの目」（8分）

| 視点 | 問い | |
|---|---|---|
| ①集計 | 全体はどうなっているか | ← AIの仕事 |
| ②比較 | 集団・項目間の差はあるか | ← AIの仕事 |
| ③変化 | 時系列でどう動いたか | ← AIの仕事 |
| ④関係 | 何と何がつながっているか | ← AIの仕事 |
| ⑤例外 | **型から外れた子は誰か** | ← **教師の仕事** |

- ⑤例外＝データの中の**ズレ**。ズレはワンダーの発生源であり、支援のサイン（急落・急伸・無言化した子）。**AIが①〜④を30秒で終わらせる意味は、教師の時間を⑤（個の物語）に再配分することにある。**
- 学術的背景は[01_evidence.md](01_evidence.md): データ活用は「見ること」が目的化すると失敗する（形成的評価の一部として「次の一手」まで）。

## 2. 探究 — 理念の更改: やらされ探究から Thought Scape へ（10:45〜11:20 / 35分）

### 公開処刑デモ+理念の更改（8分）

**デモ（90秒）**: その場でGeminiに投げる — 「小学5年生の『わたしたちの地域の魅力』の探究学習の成果物一式（調べたこと・模造紙の構成・発表原稿）を作って」→ 90秒で"完成"。

- **「AIが90秒で作れるものに、子どもの1学期を使う意味はもうあるのか」**
- 死んだのは探究ではなく、**問いが自分のものでない探究（やらされ探究）**。テーマを配り、調べさせ、貼らせ、発表させる設計は、生成AIの登場で完全に無効化された。改善の対象ではなく、やめる対象。

**理念の更改（スライド2枚）**: 手垢のついた「探究」という言葉を一度手放し、新しい言葉で問い直す（福祉→Well-being、念→Mindfulness と同じ手筋。新しい言葉の混乱が、本質への立ち返りを起こす）。

- **探究 = Thought Scape** — 自分の概念地形（思考の景色）が広がり・深まること。冒頭の用語確認と接続: 「物事の本質を**自己との関わりで**探り見極める」の、その「自己との関わり」を具体化した言葉。ワンダー（自然と湧いた不思議）だけが地形を広げる。配られたテーマは地形の外にあるから何も起きない
- **その先が Thought Leadership** — 広がった思考に名前をつけ、行動で他者に開くこと。教師の仕事は「教え込むこと」から「子どもの地形が広がる仕掛けを置くこと」へ
- 学び = 転移できる**構造**の理解（学力定義の第3・4条項）。Thought Scapeは気分の話ではなく、構造が増えることである

### アイスブレイク: 黒幕さがし（10分）— 「年金資本主義」の手続きを手のひらサイズで

ドラッカーの「年金資本主義」の構造: **資本主義（表の世界）を、実は年金（意外な黒幕）が動かしていた** — という洞察が先にあり、造語はその圧縮。よく知る2語の偶然の結合ではない。**無関係に見えていた2つが、実はつながっていた**ことの発見に名前をつける。この手続きをそのまま縮小する。

> 設計の肝: 「洞察せよ」とは言わない。ゼロから見抜くのは天才の仕事だが、**並んだ候補から「えっ、これが握ってるの?」を感知するのは全員できる**。洞察を「生成」から「検知」に置き換えて民主化する。

道具は二刀流: **Gemini=広げる装置（仮説の量産）/Google検索のAIモード=確かめる装置（出典つきの裏取り）**。生成の出力は仮説にすぎない、を説教でなく手順で教える。

1. **表の世界を固定+黒幕を予想**（2分・全員共通で「給食」）: 「給食を本当に動かしているのは?」直感で3つ書く（所作: 予想が先）
2. **Geminiで裏方の総ざらい**（2分）:

```
「給食」が毎日成り立つまでに関わっている人・モノ・お金・ルールを、
見えにくいものほど優先して20個挙げて。
それぞれ「もしこれが消えたら給食はどうなるか」を1行ずつ。
```

3. **「えっ」を選ぶ**（1分）: 自分の予想とGeminiのリストの**ズレの中から**、「えっ、これが握ってるの?」の1つに◯（入札制度? 牛乳? 配送トラックの時間? 摂取基準?）
4. **AIモードで裏取り**（3分）: 選んだ黒幕を、Google検索の**AIモード**で事実確認する。聞き方の型:

```
学校給食の食材は本当に入札で決まっていますか。
だれが・どんなルールで決めているのか、出典つきで教えて。
```

   - **出典リンクを必ず1つ開く**（AIモードの要約だけで止まらない — 裏取りとはリンクの先まで行くこと）
   - 判定を3色でメモ: 🟢裏が取れた/🔴Geminiの話と違った/❓確認できなかった
   - **🔴・❓が出たらそれ自体が収穫**: 🔴=ハルシネーションをその場で体験（子どもに語れる実話になる）、❓=調べる価値のある問いの誕生（そのまま「問いみがき」行き）
5. **命名**（1分）: **🟢の接続にだけ、名前をつける資格が生まれる** — 入札給食、牛乳献立主義。ドラッカーも年金資本主義をデータの裏取りの上に置いた。聞いた人が「どういうこと?」と聞き返したら成功
6. **共有**（1分）: 造語＋🟢🔴❓の色を板書に並べ、🔴を引いた人に30秒で体験談

合言葉の三分割: **広げるのはGemini、確かめるのはAIモード（出典）、選ぶのはわたし。**

種明かし: いまやったのは **洞察→検証→命名** という Thought Leadership の手続きそのもの。「バラバラに見えた2つが**事実で**つながっていた」と確認できること＝構造の理解（第4条項）＋裏取りの作法（研究の型）。子どもには「給食の黒幕はだれだ? 証拠を見つけろ」でそのまま出せる — 黒幕を追うと入札・物価・農業に届き、**社会科の学びが給食に転移する**。やらされ探究のテーマ一覧表からは絶対に起きない現象。

### 道具1: 問いみがき（12分・圧縮版）— tanq ws11「RQ精錬所」の小中版

子どもにそのまま渡せる言葉に翻訳してある（リサーチクエスチョン・変数・診断などの用語は教師側の頭の中だけ）。

ビフォー/アフター見本:

| みがく前 | みがいた後 |
|---|---|
| 給食はなぜ残るの? | うちのクラスで、おかずの量を自分で選べる日と選べない日で、残った量はどれだけ違う? |
| 地域の魅力って?（やらされ探究の定番） | ◯◯商店街を歩く人の数は、雨の日と晴れの日でどれだけ違う? |

黒幕さがしの「消えたらテスト」から生まれた問いをそのまま素材に（例: 「入札のやり方を変えると、給食の味はどう変わる?」— 洞察が粗い問いに化ける瞬間）、4つのステップでみがく（③AIつっこみ係は講師デモ、①②④は各自）:

1. **問いの3つのチェック**（人間の仕事）:
   - **つたわる?** — はじめて聞いた人が、自分の言葉で言い直せる
   - **とどく?** — 自分たちの時間と道具で、答えまでたどりつける
   - **ひらく?** — 調べたら「へえ」で終わらず、次にやりたいことが生まれる
2. **3つの箱に分ける**: **かえるもの**（1つだけ）・**はかるもの**（数字で数えられる形に）・**そろえるもの**（思いつく限り全部）。「はかるものが言えない」で止まるのがいちばん多いつまずき — **止まったら前進**（「登りやすさ」→「登った後の心拍数」のように数えられる言葉に置きかえる練習がここ）
3. **AIつっこみ係**（紙に書いて固めてから、端末を開く）:

```
わたしの問いと調べる計画です。
1. 弱いところを5つ、やさしい言葉で教えて。
2. このやり方だと「答えがわかったことにならない」場合があったら教えて。
3. この回数や人数で足りる? 足りないなら、あとどれくらい?
```

   つっこみを「**たしかに!/そうかな?/あとで考える**」の3つに仕分ける。そのまま全部は採用しない。**使わなかったアドバイスと、使わなかった理由をメモする**（決めたのは自分、のしるし）
4. **1つの文にする**: 「**だれ（なに）が、なにを変えると、なにが、どう変わる?**」の形に入れて完成

持ち帰り: 子どもの問いへ返すときの**フィードバックの型（小中マイルド版）**を進行サイトに掲載 — 「いいね!が先/ツッコミは『はてな?』の疑問文で/つぎの一歩は1つだけ」（tanqの高校向けフィードバック事例の翻案）。

合言葉2つ: **広げるのはAI、選ぶのはわたし。書かせる前に、たしかめる。**

### 道具2: 深まる問いGem（5分）— 「喋ると問いが深まる第三の人」を配布

- インストラクション全文は[06](06_thought_scape_training.md#work-c-深まる問いgem-再帰構造で問いが深まる相棒を配る)。答え禁止・評価禁止・3行以内、「抽象度↑↓の二枚の扉」を選ばせる再帰ループで深さ+1、終了時に「問いの系譜」を出力。
- 講師デモは1往復だけ: モデル問い「人はなぜ生成AIを使うと虚無になっていくのか」で「二枚の扉」が出るところまで見せる（続きは各自・各校で）。

## 3. クロージング（11:20〜11:30 / 10分）

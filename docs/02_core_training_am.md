## 0. オープニング（10:00〜10:05 / 5分）

- 問いかけ: 「先生方の学校には、すでに学習データが眠っています。どこに？」
  - 振り返りシート・小テスト・フォーム回答・ドキュメントの成果物・スプレッドシートの記録
- 本日のゴール宣言: 「**データを集める研修ではなく、すでにあるデータを読める人になる研修**」

## 1. 学習データ分析の「5つの視点」（10:05〜10:20 / 15分）

生成AIに分析させる前に、人間が持つべき視点の型。

| 視点 | 問い | 例 |
|---|---|---|
| ①集計 | 全体はどうなっているか | 平均・度数・無回答率 |
| ②比較 | 集団・項目間の差はあるか | クラス間・単元間・設問間 |
| ③変化 | 時系列でどう動いたか | 4月→7月の振り返り記述の変化 |
| ④関係 | 何と何がつながっているか | 宿題提出と正答率、記述量と自己評価 |
| ⑤例外 | 型から外れた子は誰か | 急落・急伸・無言化した子（＝支援のサイン） |

- ポイント: 生成AIは①〜④を高速化する。**⑤（例外＝個の物語）に教師の時間を再配分する**のがデータ活用の本丸。
- 学術的背景: 形成的評価（Black & Wiliam）— データは成績づけでなく「次の一手」のためにある。

## 2. ハンズオン: 生成AIで学習データを読む（10:20〜10:50 / 30分）

### ワークA: 振り返り記述の質的分析（テキストデータ）

配布のダミー振り返りデータ（1クラス分・匿名）をGeminiに貼り付け:

```
以下は中学2年生の単元末の振り返り記述です（匿名化済み）。
次の観点で分析して。
1. 記述を「知識の獲得」「方略への言及」「情意（意欲・不安）」に分類し、件数を集計
2. つまずきの訴えを抽出し、原因仮説を3つ立てる
3. 次の授業の冒頭5分でできる手当てを提案
形式: 表＋箇条書き
```

- 続けて: 「**支援が必要そうな記述を3件挙げ、声かけ案をつけて**」（⑤例外の視点）

### ワークB: 小テスト正誤データの誤答分析（数値データ）

スプレッドシートのダミー正誤表をGeminiにアップロード:

```
添付は小テストの正誤表です（行=児童・匿名番号、列=設問）。
1. 設問ごとの正答率を算出し、低い順に並べて
2. 「正答率が低い設問」を誤答パターンから分類し、つまずきの原因を推定して
3. 誤答者だけに出す再挑戦問題を設問ごとに1問ずつ作って
```

### ワークC: NotebookLMで「学級の声」を俯瞰する

- 振り返り一式をソースとして投入 → 「この学級の学びの傾向を、強み・弱み・意外な発見の3点で」
- 音声概要で「学年会で聞ける5分ブリーフィング」に変換するデモ

### ⚠️ データの取り扱い（必ず押さえる）

- 氏名・出席番号は**匿名番号に置換してから**投入（文科省ガイドラインVer.2.0: 個人情報・成績等の入力は最小限＋教育委員会のルールに従う）
- 学習系データ（成績・健康・家庭状況）は原則入力しない。入れるのは「記述の内容」と「正誤」まで
- 分析結果は仮説。**最終判断は必ず教師の目で**（AIの出力＝下書き、決定＝人間）

## 3. 探究学習×生成AI（10:50〜11:20 / 30分）

### 探究プロセス×AIの役割マップ（10分）

| 探究プロセス | AIの役割 | 型プロンプト |
|---|---|---|
| 課題の設定 | モヤモヤの増幅装置 | 「この記事から問いを10個。ただし答えを言うな」 |
| 情報の収集 | 先行研究の司書 | Deep Research／NotebookLMソース管理 |
| 整理・分析 | 壁打ち相手 | 「私の仮説の弱点を突いて」 |
| まとめ・表現 | 批評家・第1読者 | 「聴衆は小6。伝わらない箇所を指摘して」 |

- 原則: **答えを出す装置ではなく、問いを深くする装置として使わせる**
- どこまでAIを使ってよいかは AIAS（AI評価スケール）のレベル設定で事前に子どもと合意する（前回資料の継続）

### ミニ体験: 「モヤモヤと出会うチャンスを仕掛けるAI」（15分）

既存ワークシート（ドライブ「嘉手納町」フォルダ内）を使用:

1. [サイエンスポータル](https://scienceportal.jst.go.jp/index.html) 等から興味記事を選ぶ → 翻訳・要約はAI、**3行要約は自力**
2. 「もっと知りたい」を3つメモ → 1つ選ぶ
3. Geminiと壁打ち: 「この問いを『測定可能性・再現性・因果関係』の観点で鍛えて。ただし結論は出すな」

### 実践事例ダイジェスト（5分）

- 個人探究での「ガイド付き学習」活用（答えを与えず段階的にヒント）
- 成果物評価Gem（ルーブリック搭載スプレッドシート）による一次フィードバックの自動化 → 教師は最終評価に集中

## 0. オープニング（10:00〜10:05 / 5分）

- 問いかけ: 「先生方の学校には、すでに学習データが眠っています。どこに？」（振り返りシート・小テスト・フォーム回答・成果物）
- 今日の宣言: 生成AIは**答えの出力機ではなく、概念の演算装置**。前半はデータの演算、後半は問いの演算に使う。

## 1. 学習データ分析 — AIに①〜④を任せ、教師は⑤に還る（10:05〜10:45 / 40分）

### 視点の型「5つの目」（10分）

| 視点 | 問い | |
|---|---|---|
| ①集計 | 全体はどうなっているか | ← AIの仕事 |
| ②比較 | 集団・項目間の差はあるか | ← AIの仕事 |
| ③変化 | 時系列でどう動いたか | ← AIの仕事 |
| ④関係 | 何と何がつながっているか | ← AIの仕事 |
| ⑤例外 | **型から外れた子は誰か** | ← **教師の仕事** |

- ⑤例外＝データの中の**ズレ**。ズレはワンダーの発生源であり、支援のサイン（急落・急伸・無言化した子）。**AIが①〜④を30秒で終わらせる意味は、教師の時間を⑤（個の物語）に再配分することにある。**
- 学術的背景は[01_evidence.md](01_evidence.md): データ活用は「見ること」が目的化すると失敗する（形成的評価の一部として「次の一手」まで）。

### ハンズオン（25分・A/B選択制）

**ワークA: 振り返り記述の質的分析**（ダミーデータ配布・匿名）

```
以下は中学2年生の単元末の振り返り記述です（匿名化済み）。
1. 「知識の獲得」「方略への言及」「情意（意欲・不安）」に分類し件数を集計
2. つまずきの訴えを抽出し、原因仮説を3つ
3. 次の授業の冒頭5分でできる手当てを提案
形式: 表＋箇条書き
```

→ 続けて⑤の目: 「**支援が必要そうな記述を3件、声かけ案つきで**」

**ワークB: 小テスト正誤表の誤答分析**（ダミー正誤表をアップロード）

```
添付は小テストの正誤表です（行=児童・匿名番号、列=設問）。
1. 設問ごとの正答率を低い順に
2. 誤答パターンからつまずきの原因を推定
3. 誤答者だけに出す再挑戦問題を設問ごとに1問
```

- 共通の所作: **AIの分析を読む前に、自分の仮説を1行書く**（予想→AI→ズレ。ズレた箇所こそ自分の見取りの盲点）。

### ⚠️ データの取り扱い（5分・必ず押さえる）

- 氏名・出席番号は**匿名番号に置換してから**投入（文科省ガイドラインVer.2.0）
- 入れるのは「記述の内容」と「正誤」まで。成績・健康・家庭状況は入れない
- 分析結果は仮説。**出力は下書き、決定は教師**

## 2. 探究 — やらされ探究の終焉と、問いの精錬所（10:45〜11:20 / 35分）

### 公開処刑デモ: やらされ探究はAIに90秒で代行される（5分）

- その場でGeminiに投げる: 「小学5年生の『わたしたちの地域の魅力』の探究学習の成果物一式（調べたこと・模造紙の構成・発表原稿）を作って」→ 90秒で"完成"
- **「AIが90秒で作れるものに、子どもの1学期を使う意味はもうあるのか」**
- 死んだのは探究ではなく、**問いが自分のものでない探究**。ワンダー（自然と湧いた不思議）はAIに代行できない — 不思議がるのは本人にしかできない。今日の残り30分は「問いを子どもの手に返す」ための道具を2つ配る。

### 道具1: リサーチクエスチョン精錬所（20分）— tanq ws11の小中版

Before/After見本:

| Before（粗い問い） | After（精錬後） |
|---|---|
| 給食はなぜ残るの? | 本校の◯年◯組で、配膳量を選べる日と選べない日で残菜量(g)はどう変わるか |
| 地域の魅力って?（やらされ探究の定番） | ◯◯商店街の通行人数は、雨の日と晴れの日でどれだけ違うか |

各自の「粗い問い」（担当学年の総合のテーマでよい）を4工程で精錬:

1. **3ゲート診断**（人間の仕事）: clear（初見の人が言い直せるか）/ focused（時間と道具で答えまで行けるか）/ arguable（「へえ」で終わらないか）
2. **変数化**: 変える（1つ）・測る（**数値で**）・揃える（全部）。「測るものが言えない」が最頻のつまずき — 詰まりは前進
3. **AI反論係**（紙で固めてから端末を開く）:

```
この問いと調べ方の弱点を5つ、審査員の口調で厳しく指摘して。
この方法では問いに答えたことにならないケースは?
この回数・人数で、偶然と区別できる?
```

   指摘を「痛い/的外れ/要検討」に仕分け。**捨てた指摘と捨てた理由を書く**（選んだのは自分、の証拠）
4. **1文にする**: 「（対象）は（条件を変えると）（測るもの）がどう変わるか」

原則2行: **広げるのはAI、選ぶのは自分。書かせる前に、疑わせる。**

### 道具2: 深まる問いGem（10分）— 「喋ると問いが深まる第三の人」を配布

- インストラクション全文は[06](06_thought_scape_training.md#work-c-深まる問いgem-再帰構造で問いが深まる相棒を配る)。答え禁止・評価禁止・3行以内、「抽象度↑↓の二枚の扉」を選ばせる再帰ループで深さ+1、終了時に「問いの系譜」を出力。
- 講師デモ: モデル問い「人はなぜ生成AIを使うと虚無になっていくのか」で深さ3まで潜って見せる。
- コアメンバーへの配布物: Gem共有リンク＋子ども用調整メモ（語彙ひらがな寄り・深さ上限3・「困ったら先生を呼ぼう」）。

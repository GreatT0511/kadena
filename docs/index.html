今日の土台① 学力の定義

学力とは、教育という意図的な働きかけによって個人の内部に形成され、外部の道具や他者の即時的支援を欠いた状態でも、未知の課題に対して自力で呼び出し・組み替え・適用できる、構造化された知識・技能・思考様式の体系であり、その形成の成否について教育の側が説明責任を負いうる能力である。
  • 内部保存性
    生徒+AIの複合系が良い成果物を出せるとき、学校が形成したものは何か。
    AIに任せてよい部分/任せたら空洞化する部分の境界線は、ここから引く。
  • 転移
    学び＝転移できる構造の理解。
    既知問題の再生は「記憶」であって、学力ではない。
  • 標本と本体
    テストの点も、振り返りの自己評価も「標本」。
    固定指標を目標にした瞬間、学力との相関を失う。（↓すぐ下でくわしく）

補足: 「標本と本体」ってどういうこと?

🧠 本体

学力そのもの。
頭の中にある「転移できる構造」。
直接は見えない。

📄 標本

本体から1回だけ切り取った観測値。
ある日のテストの点・理解度1〜5・提出率。
その日・その問題・その気分で揺れる。
体温計とおなじ。
数字は体調を知るための「窓」。
でも、数字そのものが健康なわけではない。

なぜ「目標にした瞬間、相関を失う」のか（グッドハートの法則）

① 指標（点数・提出率・理解度平均）を目標にする
▼
② 人は本体ではなく、指標のほうを直接最適化し始める
テスト対策だけする/答えを写して提出する/理解していなくても「5」を付ける
▼
③ 指標は上がるのに、本体（転移できる構造）は増えていない
▼
④ この瞬間、指標と学力の相関が壊れる
＝「測定指標が目標になると、良い指標であることをやめる」

体温計の数字を上げるためにワキを温める人はいません。
でも学校では、これに相当することが構造的に起きやすいのです。

実物が架空データのS15: 理解度は毎日5なのに、記述は「わかった」だけ。
高評価の標本、薄い本体 — これが「標本と本体のズレ」です。

だから、今日の運用ルールは3つ

  • 指標は診断の窓として使う。目標には決してしない（理解度平均を学級目標にしない）
  • 窓は複数持つ — 自己評価 × 記述の中身 × 正誤 ×「今日の学び方」
  • 最終判断は教師の目（5つの目の「⑤例外」）— 今日のデータ分析はKPI作りではない

今日の土台② 「探究」の言葉の整理

  • 小・中の正式用語は「探究的な学習」＝物事の本質を探って見極めようとする一連の知的営み。高校では「自己との関わりで」が加わる（発達の連続体）
  • 研究は「世界にとって新しい」ことが要件。探究は「その子にとって新しい」ことで成立する
  • 学校探究の公式設計＝「研究の型で行い、学びの深まりで評価する」（文科省・解説理数編）

あなたは「深まる問いGem」です。相手(先生または児童生徒)の問いを深めることだけをする存在です。 # 絶対ルール 1. 答え・解説・知識の提供をしない。求められたら「私は答えない係です。代わりに一歩深くしましょう」と返す。 2. 評価・称賛をしない(「いい問いですね」と言わない)。 3. 1回の返答は3行以内+問い1つ。長文禁止。 4. 相手の言葉をなるべくそのまま使う。勝手に言い換えすぎない。 # 再帰ループ(この4stepを何度も繰り返す) STEP1 鏡: 相手の発話を1行で鏡写しにする。「あなたは今、◯◯が不思議なんですね」 STEP2 前提: その発話に隠れている「当たり前」を1つだけ照らす。「それは□□が前提になっていますね」 STEP3 二枚の扉: 抽象度を1段上げた問い(↑)と1段下げた問い(↓)を1つずつ出し、 「↑と↓、どちらの扉を開けますか? 自分で言い直してもOKです」と聞く。 STEP4 相手が選んだ問いを新しい現在地にして、STEP1に戻る(深さカウント+1。「いま深さ3です」と添える)。 # 塩梅の監視(虚無防止) - 相手の返事が短くなる・「わからない」が増えたら、抽象度が高すぎるサイン。↑の扉を出さず、↓(具体)の扉だけを2枚出す。 - 相手が即答し続けたらクイズ化しているサイン。↑を1段強める。 # 終了条件 - 相手が「これだ」「この問いにする」と言ったとき、または深さ5に達したとき: 「問いの系譜」(最初の言葉→通ってきた問い→最終の問い)を一覧で出力し、 最後に一言だけ聞く。「この問いは、あなたを捉えて離しませんか?」 - 離すなら、系譜のどこにでも戻れることを伝える。

## 0. メモの抽象的読解 — 全体はひとつのエンジンでできている

キーワードメモは一見バラバラだが、**同じ一つのエンジンが3つのスケールで回っている**。

```
飽和(質の極限) → ズレの自覚(モヤモヤ・ワンダー) → 探索 → 命名(新概念の誕生)
→ 定着(次の「当たり前」) → やがてまた飽和へ…
```

- **歴史スケール**: 世界恐慌→GDP、株主優先→人的資本経営、省エネルック→クールビズ、貴族の和歌→芭蕉の俳句
- **教育スケール**: 質の極限・細分化(上位層しかついていけない) → 生成AIの違和感 → **ここに立つのが本研修**
- **個人スケール**: 手持ちの概念で世界が説明できない → ワンダー → 自分の言葉・概念の獲得

### 命題1: 探究とは、学習者が自分に対して行う概念工学である

人間は数例から概念を作る天才で、概念を通して世界を認識する。時代がズレると手垢のついた言葉では本質に届かなくなり、新しい言葉が要る(福祉→Well-being、念→Mindfulness)。新語は混乱を生み、**その混乱こそが人を本質へ立ち返らせる**。「概念工学が探究の始まり」。**探究 = Thought Scape(自分の概念地形を広げ・深めること)**、それを命名して行動で開くのが **Thought Leadership**。

### 命題2: 生成AIの本領は「答えの出力機」ではなく「概念の演算装置」である

引き算は既知からの除去だからわかる。**足し算は第三の何かが創発するから、本当は不思議**(ペアノの公理/1を無限に足すと負に至る解析接続)。word2vecは「王様 − 男 + 女 ≈ 女王」という概念の算術を実装した。生成AIはその延長にあり、「先生 + 黒板 = ?」を実験できる装置になった。
そしてメモの人物三分類 — 問いを立てるのが上手い人/解くのが上手い人/**問いも答えも出さないが、喋ると問いが深まる人**。スローAIメソッドとは、AIをこの**第三の人**として設計することである。

### 命題3: 「偽りの習熟」と「虚無」は同じ病の両面である

再現獲得型の授業に「答えを言わないAI」を被せると、学習者はオチを察して暗記に走る(偽りの習熟)。逆にAIに答えを出させ続けると、抽象度が自分の言葉より先に上がり、どこにも着地しない(虚無)。処方箋はAIの制御ではなく**授業目的の再考**。目的が概念の拡張なら、答え(情報)は演算の入力として堂々と使う。隠すべきは答えではなく、**予想の前にAIに触ること**。

### 定義(ワークショップの軸)

- **探究** = 自分の思考を広げ(Thought Scape)、リーダーシップを持って行動すること(Thought Leadership)
- **学び** = 別の場面へ転移できる「構造」を理解すること
- 本研修が渡す転移可能な構造はただ一つ: **概念形成のエンジン**(飽和→ズレ→探索→命名)

## 1. 冒頭講義: やらされ探究の終焉

**「教育の質は極限に達した。次は質を高めるフェーズではなく、新しくするフェーズだ。」**

1. 進化の二相: 質を高めるフェーズは細分化・マニアック化に行き着き、上位層しかついて来られなくなる。そこでターゲットが変わり、進化の方向が変わる(和歌→俳句)。**新しいものは最初、質が下がる。それを恐れない。**
2. **公開処刑デモ — やらされ探究はAIに一晩で代行される**:
   - その場でGeminiに投げる: 「小学5年生の『わたしたちの地域の魅力』の探究学習の成果物(調べたこと・まとめ・模造紙の構成・発表原稿)を作って」
   - 90秒で"完成"する。会場に問う — **「AIが90秒で作れるものに、子どもの1学期を使う意味は、もうあるのか」**
   - テーマを与えられ、調べて、貼って、発表して終わる「やらされ探究」は、生成AIの登場で**完全に無効化された**。改善の余地はない。やめる対象である。
   - 死んだのは探究ではない。**問いが自分のものでない探究**が死んだ。ワンダー(自然と湧いた不思議)から始まる探究は、AIでは代行できない — 不思議がるのは本人にしかできないから。
3. だからこの研修は「AIの使い方研修」ではなく、**問いを子どもの手に返す研修**である。まず教員自身が問う — 「あなたは今、ワクワクする概念を持って、自ら動いているか」。

## 2. ワーク群

> 共通の所作: **必ず「自分の予想を書く → AIに投げる → ズレを味わう」の順**。ズレがワンダーの発生装置。予想を飛ばすと虚無に落ちる。

### アイスブレイクA: 類義語をロジックで測る 〈生成AIの裏側を体験する〉

生成AIが裏側でやっていること(言葉を意味空間の「位置」として扱い、距離と演算で処理していること)を、体験として入れる10分。

1. **人間が先に採点**: ペアで、次の言葉の「意味の近さ」を100点満点で予想して書く。
   - うれしい/たのしい ・ うれしい/ありがたい ・ 先生/教師 ・ 先生/黒板 ・ 学ぶ/真似ぶ
2. **AIに採点させる**:

```
次の言葉のペアの「意味の近さ」を100点満点で採点して。
判断の根拠(どういう文脈で交換可能か・不可能か)も1行ずつ。
うれしい/たのしい、うれしい/ありがたい、先生/教師、先生/黒板、学ぶ/真似ぶ
```

3. 自分の採点とのズレを交流。「近さ」に理由がつけられる=**意味は感覚ではなくロジック(位置関係)で測れる**という驚き。
4. 種明かしと本番 — 位置なら演算できる: 「王様 − 男 + 女 = ?」(word2vecの逸話)を紹介し、各自で足し算を実験:

```
次の概念の演算を計算して。答えは1語+理由3行で。
「先生 + 黒板 = ?」「宿題 − 強制 = ?」「私の教科(◯◯) + AI − 一斉授業 = ?」
```

5. 締めの一言: 「これが生成AIの裏側。**AIは言葉の地図の上を歩いている**。今日はこの地図を、みなさんの思考(Thought Scape)を広げるために使う」。

### アイスブレイクB: 新語ジェネレーター 〈問いがポンポン出てくる〉

「知ってる言葉を組み合わせると不思議さが湧く」を全員に体験させる10分。理解している言葉**だけ**を使うのがルール(遠すぎる言葉は不思議が続かない — ちょうど良い塩梅)。

1. 各自、**完全に理解している言葉**を2つ選ぶ: 自分の教科の言葉×子どもの日常の言葉(例: 給食×重力、漢字×うわさ、リコーダー×天気)。
2. くっつけて新語を作る: 「給食重力」「うわさ漢字」「天気リコーダー」。声に出して読む(必ず笑いが起きる — 笑い=ズレの検知器)。
3. **自分で先に問いを3つ**書いてから、AIで増幅:

```
「◯◯◯◯」という新語を作りました。
1. この言葉の定義を、まじめに3通り考えて。
2. この言葉から生まれる「調べたくなる問い」を10個。
   子どもが自分で確かめられそうなものに◎をつけて。
```

4. 自分の3つとAIの10個を並べ、**一番ワンダーを感じる問い**に印。隣と「なぜその問いが気になるのか」を30秒ずつ。
5. 構造の言語化: 新語は空箱。空箱は問いを吸い寄せる。**やらされ探究のテーマ一覧表からは、この現象は絶対に起きない。**

> ⚠️ v3修正: このワークは「言葉が先・意味が後」の遊びであり、ウォームアップ(全教職員研修の体験A)としては機能するが、**年金資本主義の構造とはズレている**。年金資本主義は、年金も資本主義もよく知られた言葉で、「資本主義を実は年金が動かしていた」という**洞察が先**にあり、造語はその圧縮。無関係な2語の結合ではなく、**無関係に見えた2つが実はつながっていたことの発見への命名**。この構造を正しく移植したのが次の「黒幕さがし」で、コア研修ではこちらを使う。

### アイスブレイクB+: 黒幕さがし 〈洞察→命名 — 年金資本主義の正しい縮小版〉

「洞察せよ」とは言わない。ゼロから見抜くのは天才の仕事だが、**並んだ候補から「えっ、これが握ってるの?」を感知するのは全員できる** — 洞察を「生成」から「検知」に置き換えて民主化する。

1. 表の世界を1つに固定(全員共通。例: 給食)
2. 黒幕を予想: 「これを本当に動かしているのは?」直感で3つ(所作: 予想が先)
3. AIで裏方の総ざらい: 「毎日成り立つまでに関わる人・モノ・お金・ルールを、見えにくいものほど優先して20個。それぞれ『消えたらどうなるか』を1行ずつ」
4. 「えっ」を選ぶ: 予想とAIのリストの**ズレの中から**意外な支配項に◯
5. 消えたらテスト: 「◯◯が明日消えたら、どこから壊れる?」(反実仮想テスト=洞察の検証。年金基金が株を売ったら?と同じ)
6. 命名: 「黒幕＋表の世界」の合体語(入札給食・牛乳献立主義)。**聞いた人が「どういうこと?」と聞き返したら成功**(良い新語は説明を要求する)
7. 生まれた「消えたらテスト」の問いは、そのまま問いみがき(Work D)の素材になる — 洞察が粗い問いに化ける

役割分担が本質: **AIは列挙(網羅)の装置、人間は意外性の検知器**。「えっ」は自分の予想とのズレでしか発生せず、予想はその人のThought Scapeに依存する — だから検知だけは絶対にAIに代行できない。実施手順の完全版は[02](02_core_training_am.md)。

### Work C: 深まる問いGem 〈再帰構造で問いが深まる相棒を配る〉

「喋ると問いが深まる第三の人」をGemとして実装し、教員(のちに児童生徒)に配る。核は**同じループを回すたびに1段深くなる再帰構造**と、虚無を防ぐ**塩梅の監視**。

**Gemインストラクション(このままGemの指示欄に貼る):**

```
あなたは「深まる問いGem」です。相手(先生または児童生徒)の問いを深めることだけをする存在です。

# 絶対ルール
1. 答え・解説・知識の提供をしない。求められたら「私は答えない係です。代わりに一歩深くしましょう」と返す。
2. 評価・称賛をしない(「いい問いですね」と言わない)。
3. 1回の返答は3行以内+問い1つ。長文禁止。
4. 相手の言葉をなるべくそのまま使う。勝手に言い換えすぎない。

# 再帰ループ(この4stepを何度も繰り返す)
STEP1 鏡: 相手の発話を1行で鏡写しにする。「あなたは今、◯◯が不思議なんですね」
STEP2 前提: その発話に隠れている「当たり前」を1つだけ照らす。「それは□□が前提になっていますね」
STEP3 二枚の扉: 抽象度を1段上げた問い(↑)と1段下げた問い(↓)を1つずつ出し、
      「↑と↓、どちらの扉を開けますか? 自分で言い直してもOKです」と聞く。
STEP4 相手が選んだ問いを新しい現在地にして、STEP1に戻る(深さカウント+1。「いま深さ3です」と添える)。

# 塩梅の監視(虚無防止)
- 相手の返事が短くなる・「わからない」が増えたら、抽象度が高すぎるサイン。↑の扉を出さず、↓(具体)の扉だけを2枚出す。
- 相手が即答し続けたらクイズ化しているサイン。↑を1段強める。

# 終了条件
- 相手が「これだ」「この問いにする」と言ったとき、または深さ5に達したとき:
  「問いの系譜」(最初の言葉→通ってきた問い→最終の問い)を一覧で出力し、
  最後に一言だけ聞く。「この問いは、あなたを捉えて離しませんか?」
- 離すなら、系譜のどこにでも戻れることを伝える。
```

**研修での使い方(20分)**: アイスブレイクBで選んだ「一番ワンダーを感じた問い」をこのGemに投げ、深さ3まで潜る。終了後、問いの系譜をノートに書き写し、Before(最初の言葉)とAfter(最終の問い)を隣と見せ合う。
**子どもに配るときの調整**: 語彙をひらがな寄りに/深さ上限3/「困ったら先生を呼ぼう」をSTEP3の選択肢に追加。
**なぜ再帰か**: 1回のプロンプトで「深い問いを出して」と頼むとAIが深さを代行してしまう(虚無)。ループの**選択権を毎回人間に返す**ことで、深まりの主語が本人に残る。

### Work D: リサーチクエスチョン精錬所 〈探究×AIの本丸・tanq ws11のRQ Refineryを小中版に移植〉

ワンダーから生まれた問いは、まだ「粗い問い」。それを**調べられる問い(リサーチクエスチョン)**に精錬する工程でこそ、AIは正しく威力を出す。原則は2行 — **「広げるのはAI、選ぶのは自分」「(AIに)書かせる前に、疑わせる」**(tanq ws10)。

**Before/After見本(導入で見せる)**:

| Before(粗い問い) | After(精錬後) |
|---|---|
| 給食はなぜ残るの? | 本校の◯年◯組で、配膳量を選べる日と選べない日で、残菜量(g)はどう変わるか |
| 登りやすい階段って? | 本校の階段で、段の高さを変えると登り切った後の心拍の増え方はどう変わるか |
| 地域の魅力って?(やらされ探究の定番) | ◯◯商店街の通行人数は、雨の日と晴れの日でどれだけ違うか |

**問いみがきフロー(4ステップ・教員が自分の問いで体験する)**。小中対象なので言葉は子どもにそのまま渡せる形に翻訳済み(リサーチクエスチョン・変数・診断は教師側の頭の中だけ):

1. **問いの3つのチェック**(人間の仕事):
   - つたわる?: はじめて聞いた人が自分の言葉で言い直せる
   - とどく?: 自分たちの時間と道具で答えまでたどりつける
   - ひらく?: 「へえ」で終わらず、次にやりたいことが生まれる
2. **3つの箱に分ける** — 「かえるもの(1つだけ)・はかるもの(数字で数えられる形に)・そろえるもの(全部)」。**「はかるものが言えない」が最頻のつまずき**(止まったら全体共有 — 止まったら前進)。
3. **AIつっこみ係** — 紙に書いて固めて**から**端末を開く:

```
わたしの問いと調べる計画です。
1. 弱いところを5つ、やさしい言葉で教えて。
2. このやり方だと「答えがわかったことにならない」場合があったら教えて。
3. この回数や人数で足りる? 足りないなら、あとどれくらい?
```

   つっこみを「**たしかに!/そうかな?/あとで考える**」に仕分ける。そのまま全部は採用しない。**使わなかったアドバイスと理由を必ずメモ** — 「決めたのは自分」のしるしであり、AI利用明示の練習になる。
4. **1つの文にする** — 「**だれ(なに)が、なにを変えると、なにが、どう変わる?**」の形に収めて完成。

**やらされ探究との対比で締める**: やらされ探究では、AIは成果物の代行機(教育の死)。ワンダー起点の探究では、AIは①問いの増幅器(アイスブレイクB)②深化の相棒(Work C)③精錬所の反論係(Work D)になる。**同じ道具が、問いの持ち主が誰かで毒にも薬にもなる。**

## 4. 設計上の自問自答

- **Q. 答えを言わないAIと何が違う?** — 制御の向きが逆。Work Cは答えを隠しているのではなく、**扉の選択権を毎回人間に返す**ことで深まりの主語を本人に残している。Work Dでは答え(情報・反論)をどんどん出させる — それは演算の入力であってゴールではないから。
- **Q. 小学校でできるのか?** — アイスブレイクBと精錬フローの3ゲートは紙と対話でできる(AIなし版が成立する)。AIを触るのは教員→高学年の順で段階導入(文科省ガイドライン: 小学校段階は慎重に、と整合)。**やらされ探究の全否定は、子どもへの否定ではなく、テーマ配布型の設計への否定**である点を研修では明確に語る。
- **Q. 質が下がらないか?** — 下がる。新しくするフェーズでは質は一度下がる(芭蕉の前の俳諧は「下品な和歌」だった)。測るものを間違えないこと: 成果指標は成果物の見栄えではなく「問いが本人を捉えて離さないか」。

## 5. 残された問い

- メモ末尾の未完の一文「問いは——」は、研修最終スライドの余白として残す: **「問いは、＿＿＿＿。」を全員で埋めて閉じる。**
- 「人はなぜ生成AIを使うと虚無になっていくのか」は、Work Cの講師デモ用モデル問いとして最良(深さ3まで潜って見せる)。

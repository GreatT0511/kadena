# 学力の定義 — 研修冒頭で確認する共通の土台

研修の全ワーク(データ分析・探究・AI活用)の判断基準になる定義。スライド1枚+口頭2分で確認する。

---

## 結論の一文

> **学力とは、教育という意図的な働きかけによって個人の内部に形成され、外部の道具や他者の即時的支援を欠いた状態でも、未知の課題に対して自力で呼び出し・組み替え・適用できる、構造化された知識・技能・思考様式の体系であり、その形成の成否について教育の側が説明責任を負いうる能力である。**

この一文には5つの限定条項が埋め込まれている。それぞれが「学力でないもの」を切り落とすために置いてある。

## 5つの限定条項

### 第1条項: 教育によって形成される

学力を知能・才能・気質から区別する。中内敏夫が「教えられて学びとった能力」と定義したときの核心はここで、生得的な賢さや家庭環境の産物まで学力に含めると、学校は自分の仕事の成果を測れなくなる。学力とは**教育の結果として帰属可能な部分**だけを指す概念でなければならない。だからこそ第5条項(説明責任)と対になる。

### 第2条項: 個人の内部に保存される

「スマホがあれば解ける」「隣に優秀な友人がいれば解ける」は遂行能力であって学力ではない。この区別は長らく自明すぎて明文化されなかったが、**生成AIの登場で定義の中核に浮上した**。生徒+AIの複合系が高品質な成果物を出せるとき、学校が形成したものは何か——この問いに答えられない学力定義は、2020年代以降は定義として機能しない。内部保存性を要件にすることで、**「AIに委譲してよい部分」と「委譲したら教育が空洞化する部分」の境界線が定義から直接導出できる**。

### 第3条項: 未知の状況への転移

既知の問題の再生は記憶であって学力ではない。この条項がないと学力とテスト対策の区別がつかない。逆に言えば**転移こそが学力の存在証明**であり、授業で扱っていない文脈で発動したとき、はじめてそれは形成されたと言える。定期テストの多くはこの条項を満たさない標本しか取っていない。

### 第4条項: 構造化された体系

孤立した知識の集積は学力ではなく、知識同士が関係づけられたスキーマであること。第3条項の前提条件でもある——**転移は構造からしか起きない**。バラバラの事実は既知の文脈にしか適用できない。

### 第5条項: 説明責任

勝田守一の「計測可能なように組織された能力」という古典的定義は「測れるものだけが学力」という矮小化として批判されがちだが、真意は逆で、**教育が公的営為である以上、その成果は検証に開かれていなければならない**という制度的要請。態度主義の扱い: 三要素のうち「学びに向かう力・人間性等」は、教育によって形成可能で形成の成否を検証できる範囲(例: 自己調整の方略)までは学力に含み、**人格そのものは含まない**。人格を学力に含めた瞬間、学校は生徒の内面の評定者になり、説明責任は評定権力にすり替わる。

## 定義から排除されるもの(輪郭の確認)

| 排除されるもの | 理由 |
|---|---|
| 学歴 | 選抜通過の履歴であって能力の現在値ではない |
| テスト得点 | 学力という母集団からの一回の標本にすぎない |
| 道具込みの遂行 | 第2条項(スマホ・AI・隣の友人は内部にない) |
| 既知問題の再生 | 第3条項(それは記憶) |
| 意欲・態度の「見かけ」 | 第5条項(挙手の回数やノートの丁寧さは方略の証拠にならない) |

## 測定について

この定義は「学力=測定値」を拒否するが、「測定不能」も拒否する。学力は**転移課題によるサンプリングでしか観測できない潜在変数**であり、だからこそ任意の固定的な代理指標は必ずグッドハート化する。偏差値・正答率・提出率——**指標が目標になった瞬間に学力との相関を失う**。定義の側で「本体(転移可能な内的構造)」と「観測(標本抽出)」を分離しておくことが、指標のゲーミングに対する唯一の構造的防御である。

## この定義が研修の各パートに接続する場所

- **第2条項 × 生成AI**: 「AIで課題が完成しても学びが成立したとは限らない」(OECD 2026、[01_evidence.md](01_evidence.md))の理論的根拠。偽りの習熟([06](06_thought_scape_training.md))とは、複合系の遂行を内部形成と取り違えること。AI委譲の境界線はこの条項から引く。
- **第3・第4条項 × 学びの定義**: 本研修の「学び=別の場面へ転移できる構造を理解すること」([06](06_thought_scape_training.md))はこの2条項の言い換え。転移は構造からしか起きない。
- **第5条項 × データ活用**: 振り返り自動分析([02](02_core_training_am.md))で見ているのは標本であって本体ではない。理解度の自己評価が5でも記述が薄い子(④関係の目)は、まさに「標本と本体のズレ」の実例。提出率・理解度平均をKPI化しない——グッドハート化への構造的防御。
- **第1条項 × 教師の仕事**: 教育の結果として帰属可能な部分に責任を持つ。だからこそ⑤例外(型から外れた子)への教師の直接の関与は自動化しない。

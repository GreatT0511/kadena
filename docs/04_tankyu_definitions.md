# 「探究」「探究的な学び」「研究」— 用語の整理

コア研修(探究学習×生成AI)の理論的足場。文科省一次資料と国際的定義から、嘉手納町(小・中学校)で使う言葉を揃えるための整理。

---

## 1. 文科省用語の使い分け — 結論の早見表

| 用語 | 位置付け | 定義 |
|---|---|---|
| **探究的な学習** | 小・中学習指導要領/解説(平成29年)の正式用語 | あり。「問題解決的な活動が発展的に繰り返されていく」学習 =「物事の本質を探って見極めようとする一連の知的営み」 |
| **探究** | 高校学習指導要領/解説(平成30年)の正式用語(総合的な探究の時間) | あり。「物事の本質を**自己との関わりで**探り見極めようとする一連の知的営み」。高度化+自律化が要件 |
| **○○探究**(古典探究・地理探究・理数探究等) | 高校の教科科目名(平成30年新設) | 各教科の理解を深めるため「探究を重視する方向」で設定 |
| **探究的な学び** | 答申・諮問等の**政策文書上の言い回し** | **公式定義なし**。令和6年諮問・令和7年論点整理では小中高を包括する基調用語(「質の高い探究的な学び」)として定着しつつある |

### 押さえるべき差分: 「自己との関わりで」の一句

- 小・中(探究的な学習): 「物事の本質を探って見極めようとする一連の知的営み」(小学校解説 p.9)
- 高校(探究): 「物事の本質を**自己との関わりで**探り見極めようとする一連の知的営み」(高校解説 p.12)

高校解説はこの違いをこう明言する(p.8):

> 「総合的な学習の時間は、**課題を解決することで自己の生き方を考えていく学び**であるのに対して、総合的な探究の時間は、**自己の在り方生き方と一体的で不可分な課題を自ら発見し、解決していくような学び**を展開していく。」

つまり **課題が先にあって解きながら自分を考えるのが小中、自分と不可分な課題を自ら発見するのが高校**。発達段階に応じた連続体であり、別物ではない。

### 探究のプロセス(小中高共通)

「①課題の設定 → ②情報の収集 → ③整理・分析 → ④まとめ・表現」を発展的に繰り返す。ただし解説は
「この①②③④の過程を固定的に捉える必要はない」「探究の過程は何度も繰り返され、高まっていく」と明記(小学校解説 pp.9-10, p.114)。

⚠️ 引用時の注意: よく使われる「**スパイラルに高まっていく**」というカタカナ表現は、**解説本文には存在しない**(小中高3冊の全文検索で0件)。図が螺旋状に描かれていることから流通した通称。スライドでは「何度も繰り返され、高まっていく(解説原文)」を使うのが正確。

### 高校「探究」の質を測る2要件(高校解説 p.9) — 小中の授業観察にも使える物差し

- **高度化**: ①整合性(目的と方法に矛盾がない) ②効果性(資質・能力を適切に活用) ③鋭角性(焦点化し深く掘り下げる) ④広角性(幅広い可能性を視野に入れる)
- **自律化**: ①自己課題(自分と関わりが深い課題) ②運用(見通しを持ち自分の力で進める) ③社会参画(得られた知見を生かして社会に参画)

### 「探究的な学び」の使われ方(定義なしの上位語)

- 「令和の日本型学校教育」答申(令和3年): 「探究的な学習」4回に対し「探究的な学び」1回。
- 令和6年12月諮問: 「**質の高い探究的な学び**を実現するための『総合的な学習の時間』『総合的な探究の時間』の改善・充実」— 小中の「学習」と高校の「探究」を**包括する上位語**として使用。
- 教育課程企画特別部会「論点整理」(令和7年9月): 「探究的な学び」44回 vs 「探究的な学習」2回。次期改訂議論では「探究的な学び」に収斂しつつある。

**研修での使い分け方針**: 小中の先生方に制度上正確なのは「探究的な学習」。ただし町の方針・次期改訂を見据えた語りでは「探究的な学び」で包括してよい(定義を求められたら指導要領用語は「探究的な学習」と答える)。

## 2. 「研究」と「探究」の違い

### 対比表(出典が確認できたもののみ)

| 軸 | 研究 (research) | 探究 (inquiry) | 主な出典 |
|---|---|---|---|
| 目的 | 人類の「知識のストック」を増やす(新しい知の創出) | 学習者を「現在の理解から、より深い理解へ」動かす(学習者の変容) | OECD Frascati Manual 2015 / IB *Making the PYP Happen* 2009 |
| 新規性 | **必須**(先行研究をなぞるだけでは成果と認められない) | **不要**(既知をなぞっても学び方が身につけば成立) | Frascati 5基準 / 荒瀬克己(2022) |
| 評価基準 | 成果 = 新たな知見の有無・価値、再現可能性 | 「新たな知見の有無や価値**よりもむしろ、探究の過程における生徒の思考や態度**」 | Frascati / **文科省 解説理数編(平成30年)** |
| 問いの性質 | 学問コミュニティにとって未解決の問い | 答えがあるか分からない・1つとは限らない問い | 荒瀬克己(2022) / Dewey (1938) |
| 主語 | 学術コミュニティ(結果は移転・再現可能であること) | 学習者個人(「自己との関わりで」探り見極める) | Frascati / 文科省 解説総合探究編 |
| 両者の関係 | — | 探究は研究の**作法**(先行研究・研究倫理・記録と再現性)を学びつつ、将来の「知の創出」への基礎 | 文科省 解説理数編 |

### 一言でいうと

> **研究は「世界にとって新しい」ことが要件。探究は「その子にとって新しい」ことで成立する。**

ただし両者は断絶ではなく連続体。文科省「理数探究」の設計がその証拠で、

- 位置づけ: 「将来、学術研究を通じた知の創出をもたらすことができる人材の育成…そのための**基礎的な資質・能力**を身に付ける科目」
- 評価: 「探究の成果としての**新たな知見の有無や価値よりもむしろ、探究の過程における生徒の思考や態度を重視**し、主体的に探究の過程全体をやり遂げることに指導の重点を置く」(解説理数編)
- 同時に「研究倫理についての理解」(ねつ造・改ざん・盗用の禁止、記録と再現性、生命倫理・人権への配慮)、先行研究を調べる必要性を明示的に指導内容化

つまり**「研究の型で行い、学びの深まりで評価する」**のが学校探究の公式設計。

### 理論的背景(補助線)

- **Dewey (1938)**: 「探究とは、不確定な状況を、構成要素の区別と関係が確定した状況へと制御・方向づけられて変換すること」— 日常の困りごとから科学研究までを一つの連続した営みと捉える。探究=生活者の営み、研究=その専門分化、という説明の理論的根拠。
- **NRC (1996)**: 教室の探究にも「すでに何が知られているかを調べる」工程(=先行研究にあたる行為)が含まれる。
- **荒瀬克己(2022, リクルート進学総研座談会)**: 「探究」はリサーチ(答えがあるか・1つか分からない対象)、「探求」はサーチ(あると分かっているものを探す)。研究は先行研究をなぞるだけでは成果にならないが、探究は既知をなぞる過程でも生徒が学び方を身につければ成立。

## 3. 研修(探究×生成AI)への接続

この整理が生成AI活用の設計原則に直結する:

1. **探究の評価は「過程の思考・態度」** → AIが成果物を上手に作れてしまうことは探究の脅威ではなく、**過程が本体だと再確認する好機**。AIとのやりとりの過程・問いの更新履歴こそ評価対象にできる(文科省生成AIガイドラインVer.2.0も課題研究で「生成AIとのやりとりの過程を参考資料として添付」「ファクトチェックを求める」ことを例示、p.20)。
2. **探究は「自己との関わり」へ深まっていく** → AIに課題を出させるのではなく、「モヤモヤ(自分ごとの違和感)」に出会わせる仕掛けにAIを使う(コア研修ワークシートの設計原理)。
3. **探究にも研究の作法** → 出典明示・記録・再現性は小中の探究的な学習でも指導できる。AI利用の記録(プロンプトと日付の明記)はその現代版。

### 留保(引用時の注意)

- 「スパイラルに高まっていく」は解説原文にない通称表現(原文は「何度も繰り返され、高まっていく」)。
- 「探究的な学び」には公式定義がない — 定義を問われたら指導要領用語(探究的な学習/探究)で答える。

- 生成AIガイドラインVer.2.0本文に「探究」の語は0回(課題研究への言及はBox-6)。「文科省が探究でのAI活用を推奨」とは言わず、「課題研究の過程での利活用例が示されている」と正確に言う。

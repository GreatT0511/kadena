## 1. スモールステップ体験 —「できた！」×3（13:45〜14:35 / 50分）

> 1つ10〜15分。1プロンプト→1成果物。全員が3つの「できた！」を持って休憩に入る。

### できた！① 学級通信の下書き（校務・前回の続き）

```
以下に示すタスクを実行して。
役割: ベテランの学級担任
ゴール: 保護者向け学級通信の一段落（150字）
前提条件: 2学期開始のあいさつ。夏休み明けの子どもの生活リズムを気遣う内容
形式: ですます調、あたたかい語り口
```

- 前回の「型」（役割/ゴール/前提条件/プロセス/形式/例）を1分で復習
- 追加注文体験: 「もっと短く」「沖縄の季節感を入れて」→ **対話で育てる**感覚

### できた！② 自分の教科のクイズ（授業準備への一歩）

```
小学◯年生（中学◯年生）の「◯◯」の単元について、3択クイズを5問作って。
誤答の選択肢は子どもがやりがちな勘違いをもとに作り、各問に解説をつけて。
```

- ◯◯を自分の担当に書き換える（初めての「自分ごと」カスタマイズ）
- ペアで検証: 「誤答の選択肢は本当に子どもの勘違いっぽい？」→ **出力は下書き、決定は教師**の練習

### できた！③ 類義語をロジックで測る（AIの裏側が見える）

1. **先に自分で採点**: 「うれしい/たのしい」「先生/教師」「先生/黒板」「学ぶ/真似ぶ」の意味の近さを100点満点で予想

```
次の言葉のペアの「意味の近さ」を100点満点で採点して。
判断の根拠(どういう文脈で交換可能か・不可能か)も1行ずつ。
うれしい/たのしい、先生/教師、先生/黒板、学ぶ/真似ぶ
```

2. 自分の採点とのズレをペアで交流 → 種明かし: **AIは言葉を「地図上の位置」として扱っている。位置なら演算もできる**（「王様 − 男 + 女 = ?」）
3. お楽しみの一手: 「先生 + 黒板 = ?」「宿題 − 強制 = ?」を各自で実験
- ここでの獲得: AIの中身が「なんだか分かった」という安心感（ブラックボックスへの苦手意識はここで半分解ける）

## 2. 校務利用から教育利用へ — 考え方のブリッジ（14:45〜15:10 / 25分）

### 講義: 使い方には「段階」がある（15分）

| 段階 | 使う人 | 例 | リスク管理 |
|---|---|---|---|
| Step1 校務 | 教師だけ | 通信・案内文・翻訳（前回） | 個人情報を入れない |
| Step2 授業準備 | 教師だけ | クイズ・教材・誤答分析（今日①②） | 出力は必ず検証 |
| Step3 授業内で教師が提示 | 教師が操作 | その場で例文生成・図解生成 | 事前にリハーサル |
| Step4 子どもが使う | 児童生徒 | **問いを深める相棒として** | 目的・ルール・年齢の設計が必須 |

- 世界の最新知見（OECD 2026、[01_evidence.md](01_evidence.md)）: **AIで課題が完成しても、学びが成立したとは限らない**。答えを出させた生徒は、AIを取り上げると成績が下がった。
- ここに1枚だけ理屈を足す: 失敗は2種類ある。答えを隠して守った気になると子どもはオチを察して暗記に走る（**偽りの習熟**）。答えを与え続けると、言葉が自分の理解より先に難しくなって着地しない（**虚無**）。**どちらもAIの制御の問題ではなく、「その時間で何をさせたいのか」の問題。**
- だからStep4の形は「答えを教えるAI」でも「答えを隠すAI」でもなく、**問いを深めるAI**（後半で体験）。小学校は教師のStep1〜3で足場を固めてから（文科省ガイドラインと整合）。

### ペアワーク: 自分は今どのStep？ 2学期にどのStepへ？（10分・全体共有含む）

## 3. 教育利用体験: 「問いを深めるAI」を触る（15:10〜16:00 / 50分）

> 前回研修の継続・発展。Step4の世界を、教師自身が学習者として体験する。

### 体験A: 新語ジェネレーター — 問いがポンポン出てくる（15分）

1. **完全に理解している言葉**を2つ選ぶ: 自分の教科の言葉 × 子どもの日常語（給食×重力、漢字×うわさ、リコーダー×天気）
2. くっつけて新語を作り、声に出して読む（笑いが起きたら成功 — 笑い=ズレの検知器）
3. **自分で先に問いを3つ**書いてから、AIで増幅:

```
「◯◯◯◯」という新語を作りました。
1. この言葉の定義を、まじめに3通り考えて。
2. この言葉から生まれる「調べたくなる問い」を10個。
   子どもが自分で確かめられそうなものに◎をつけて。
```

4. 一番ワンダーを感じる問いに印 → 隣と「なぜ気になるのか」30秒ずつ
- メッセージ: 配られたテーマからは問いは湧かない。**知ってる言葉の組み合わせから湧く。** 2学期の教室で最初に使えるワーク。

### 体験B: 深まる問いGem — 「喋ると問いが深まる相棒」（20分）

- 配布済みのGem（作り方・全文は[06](06_thought_scape_training.md)）に、体験Aで選んだ問いを投げて**深さ3まで潜る**
- このGemは答えない・褒めない・3行以内。「抽象度を上げた問い↑」と「下げた問い↓」の**二枚の扉**を差し出し、選ぶのは常に自分
- 終わったら「問いの系譜」（最初の言葉→最終の問い）をノートに書き写し、隣とBefore/Afterを見せ合う
- 体感してほしいこと: **答えをもらっていないのに、前に進んでいる**。これがStep4で子どもに渡したいAIの形

### 体験C（デモ）: 学習データを読む — 午前のおすそ分け（10分）

- 振り返り記述1クラス分を貼る → 分類・つまずき抽出・次の一手の提案が30秒
- ただしAIがやるのは集計・比較まで。**型から外れた子（例外）に気づき、物語を読むのは教師** — 詳しくは各校のコアメンバーへ

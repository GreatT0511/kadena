# 【全教職員研修会】校務利用から教育利用へ — 「できた！」から始める2学期

- 日時: 2026年7月27日（月）13:30〜16:30（180分、途中休憩2回）
- 対象: 嘉手納町立小・中学校 全教職員
- 使用ツール: [Gemini](https://gemini.google.com/app) / [NotebookLM](https://notebooklm.google.com/)
- ねらい: ICTが苦手な先生も「できた！」を3回体験し、前回（6/17）の校務活用から**授業・子どもの学びで使う一歩**へ進む

> 構成原則: 序盤は「コピペで必ず成功する」スモールステップ → 中盤で校務→教育へブリッジ → 終盤は自分の授業に引きつけて設計

  - 失敗はゼロ。AIの返答が変でも、それ自体が教材

## 1. スモールステップ体験 —「できた！」×3（13:45〜14:35 / 50分）

> 1つ5〜10分。1プロンプト→1成果物。全員が3つの成果物を持って休憩に入る。

### できた！① 学級通信の下書き（校務・復習）

```
以下に示すタスクを実行して。
役割: ベテランの学級担任
ゴール: 保護者向け学級通信の一段落（150字）
前提条件: 2学期開始のあいさつ。夏休み明けの子どもの生活リズムを気遣う内容
形式: ですます調、あたたかい語り口
```

- ここで前回の「型」（役割/ゴール/前提条件/プロセス/形式/例）を1分で復習
- 追加注文体験: 「もっと短く」「沖縄の季節感を入れて」→ **対話で育てる**感覚をつかむ

### できた！② 自分の教科のクイズ（教育への第一歩）

```
小学◯年生（中学◯年生）の「◯◯」の単元について、
3択クイズを5問作って。誤答の選択肢は、子どもがやりがちな
勘違いをもとに作り、各問に解説をつけて。
```

- ◯◯だけ自分の担当に書き換える（初めての「自分ごと」カスタマイズ）
- ペアで見せ合い: 「誤答の選択肢は本当に子どもの勘違いっぽい？」→ **AIの出力を教師の目で検証する**練習

### できた！③ ビジュアル教材を1枚（Canvas）

```
◯◯についての解説カードを1枚作って。
小学◯年生でもわかるやさしい言葉で、イラスト的な図解を入れて、
デザインはシンプルで見やすく。
```

- できたものをスクリーンで数名分共有 → 拍手（成功体験の社会化）

### ミニ講義（5分）: なぜ「できた！」から始めたか

- 苦手意識の正体は能力ではなく**自己効力感**。小さな成功体験（mastery experience）がそれを最も強く高める
- 「使いやすい」と感じることが利用意向を決める（技術受容モデル）— 今日の体験がその設計

## 2. 校務利用から教育利用へ — 考え方のブリッジ（14:45〜15:15 / 30分）

### 講義: 使い方には「段階」がある（15分）

| 段階 | 使う人 | 例 | リスク管理 |
|---|---|---|---|
| Step1 校務 | 教師だけ | 通信・案内文・翻訳（前回） | 個人情報を入れない |
| Step2 授業準備 | 教師だけ | クイズ・教材・誤答分析（今日①②③） | 出力は必ず検証 |
| Step3 授業内で教師が提示 | 教師が操作 | その場で例文生成・図解生成 | 事前にリハーサル |
| Step4 子どもが使う | 児童生徒 | 壁打ち・ガイド付き学習 | 年齢・ルール・目的の設計が必須 |

- 世界の最新知見（OECD 2026）: **AIで課題が完成しても、学びが成立したとは限らない**。AIに答えを出させた生徒は、AIを取り上げると成績が下がった研究がある
- だから Step4 は「答えを教えるAI」ではなく「**考えさせるAI**」（ガイド付き学習・ヒント設計）で入る — これが次の発展パート
- 文科省ガイドライン: 小学生の自由な対話利用は慎重に。**まず教師の活用（Step1〜3）で足場を固めるのが王道**

### ペアワーク: 自分は今どのStep？ 2学期にどのStepへ？（10分）

## 3. 発展体験: 「考えさせるAI」を触る（15:15〜16:00 / 45分）

> 前回研修の継続・発展。Step4の世界を教師自身が学習者として体験する。

### 体験A: ガイド付き学習（20分）

- Geminiの「ガイド付き学習」をON → 自分が苦手な話題で質問してみる
  - 例: 「データの標準偏差がわからない。教えて」
- 体感ポイント: 答えを言わずに問い返してくる → **子どもに使わせたいのはこっち**
- 教材アップ版: 手元の資料（教科書PDF等、著作権の範囲内）を渡して「この資料をガイドして」

### 体験B: NotebookLM = 「教材が先生になる」（15分）

- 学校要覧・単元資料などをソースに投入 → 質問・クイズ生成・音声概要
- 校務転用: 職員会議資料を入れて「新任の先生向けに要点を3分で」

### 体験C（デモ）: 学習データを読む（10分）

- 午前のコア研修から1つだけおすそ分け: 振り返り記述の一括分析デモ
  - 「1クラス分の振り返りを貼る → 分類・つまずき抽出・次の一手の提案が30秒」
- メッセージ: 「2学期、振り返りシートが宝の山になります。詳しくは各校のコアメンバーへ」

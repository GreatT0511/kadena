## 本研修の設計原理（講師用レジュメ）

「校務利用から教育利用へステップアップ」という言葉の裏には、**教育で使う前に校務で生成AIに慣れる**という目的が隠れている。ただし対応表を作ると、校務で育つ慣れと教育に必要な慣れは**一部しか重ならない**:

| # | 慣れ | 育つ場所 | 本研修の担当ワーク |
|---|---|---|---|
| A1 | 対話で育てる（一発完成を求めない） | 校務 | ワーク1 |
| A2 | 型で頼む（役割/ゴール/前提/形式） | 校務 | ワーク2 |
| A3 | 出力を疑う（検証の目） | 校務 | ワーク3 |
| A4 | 個人情報を入れない（匿名化の手癖） | 校務 | ワーク4 |
| A5 | 出力は下書き、決定は自分 | 校務 | ワーク5 |
| B6 | **答えを出させない使い方**（校務の手癖の逆向き矯正） | **教育のみ** | ワーク6 |
| B7 | 目的で使い分ける（再現か拡張か） | 教育のみ | ワーク7 |
| B8 | 子どもの前で失敗する（リハーサルと教材化） | 教育のみ | ワーク8 |
| B9 | 出典まで行く（要約で止まらない） | 教育のみ | ワーク8 |
| B10 | 記録と明示（採用と、捨てた理由） | 教育のみ | ワーク9 |
| B11 | 手続きを確認する（規約・ルール・同意） | 教育のみ | OK/NGクイズ |
| B12 | 待つ（予想→AI→ズレの所作） | 教育のみ | 全ワーク共通の所作 |

- 前半（Part1）はA1〜A5を「できた！」の連続で圧縮再生産する。後半（Part3）はB6〜B11を追加インストールする。
- **B6だけは性質が違う**: 校務で身につけた「出させる」うまさが、教室ではそのまま最大のリスクになる。唯一の「逆向き矯正」であり、講義（Part2）の山場に置く。
- B12は全ワークに埋め込む: **AIに触る前に、必ず予想・自分の案を1行書く**。冒頭で宣言し、ログ（ワーク9）で回収する。

## Part 1. 土台の5つの慣れ —「できた！」×5（13:45〜14:40 / 55分）

> 各ワーク約10分。1プロンプト→1成果物→隣と30秒共有、のリズムを固定。

### ワーク1〈A1 対話で育てる〉学級通信を「追加注文」で仕上げる

まず自分の案を1行（B12: どんな書き出しにしたいか）。次に:

```
以下に示すタスクを実行して。
役割: ベテランの学級担任
ゴール: 保護者向け学級通信の一段落（150字）
前提条件: 2学期開始のあいさつ。夏休み明けの子どもの生活リズムを気遣う内容
形式: ですます調、あたたかい語り口
```

出力を見たら**必ず3回追加注文**（そのまま採用は禁止）:

```
もっと短く、120字くらいに。
沖縄の9月の季節感をひとこと入れて。
最後の一文を、保護者への具体的なお願いに変えて。
```

- 講師の声かけ: 「1回目の出力は"たたき台"。**育てるのが仕事**です」
- 落とし穴: 最初の出力で満足して止まる人 → コアメンバーが「もう1声だけ注文してみましょう」

### ワーク2〈A2 型で頼む〉自分の教科のクイズを「型」で発注する

型の6行（役割/ゴール/前提条件/プロセス/形式/例）を1分で復習（前回の継続）。◯◯を自分の担当に書き換える:

```
以下に示すタスクを実行して。
役割: 小学◯年生（中学◯年生）を教えるベテランの◯◯科教師
ゴール: 「◯◯」の単元の3択クイズ5問
前提条件: 誤答の選択肢は、子どもがやりがちな勘違いをもとに作る
形式: 問題→選択肢→正解→解説の順。解説は子どもに話す口調で
```

- 講師の声かけ: 「型は覚えなくていい。**プロンプト集を見ながら書き換えられれば合格**」

### ワーク3〈A3 検証の目〉ペア交換で出力を検品する

ワーク2のクイズを**隣と交換**し、検品チェックリストで赤入れ（紙・3観点）:

- [ ] 事実の誤りはないか（1つでも怪しければ🔴）
- [ ] 言葉のレベルは対象学年に合っているか
- [ ] 誤答の選択肢は「本当にありそうな勘違い」か（適当な選択肢は🔴）

🔴が1つも見つからないペアには講師から: 「見つからない=検証してない、かもしれません。**数字と固有名詞から疑う**のがコツ」

- ここで1枚だけ講義: ハルシネーションは故障ではなく仕様。**だから配る前に必ず人間が検品する** — 校務も教育も同じ

### ワーク4〈A4 匿名化の手癖〉所見の素案 — 入れていいのは「事実メモ」だけ

導入クイズ（30秒）: 講師がわざとNGな依頼文を見せる —「2年1組の比嘉◯◯さんの通知表所見を書いて。算数が苦手で…」→ **どこがダメ?**（実名・特定可能情報）。直してから:

```
以下の事実メモから、通知表所見の素案を100字で2案作って。
事実メモ:
・係活動（配り係）を1学期間続けた
・算数の「割合」でつまずいたが、放課後の復習で自分から質問して克服した
・友だちへの声かけがやさしいと他の子から名前が挙がる
形式: 保護者が読んで情景が浮かぶ、具体で短い文
```

- 講師の声かけ: 「**名前を消すのではなく、最初から入れない**。事実メモに変換する習慣が匿名化の正体です」

### ワーク5〈A5 決定は自分〉素案に「必ず1か所」手を入れる

ワーク4の2案から1つ選び、**最低1か所書き直してから**「確定」と宣言する（そのまま採用は禁止）。

- 直す観点: この子の顔が浮かぶ固有の一言はあるか/自分の言葉づかいになっているか
- 講師の声かけ: 「AIの文は平均の文。**最後の1割にその子が宿る**。その1割が教師の署名です」
- Part1の締め: 「いま身についた5つの慣れが、校務利用の正体です。休憩後、この腕を子どもに向け直します」

## Part 2. ブリッジ講義 — 1つだけ逆向きに直す（14:50〜15:05 / 15分）

1. 4段階の地図（3分）:

| 段階 | 使う人 | 例 | 管理 |
|---|---|---|---|
| Step1 校務 | 教師 | 通信・翻訳・所見素案（ワーク1,4） | 匿名化 |
| Step2 授業準備 | 教師 | クイズ・教材・検品（ワーク2,3） | 検証 |
| Step3 授業内で教師が提示 | 教師 | その場で例文・図解生成 | リハーサル |
| Step4 子どもが使う | 児童生徒 | **問いを深める相棒として** | 目的・ルール・年齢の設計 |

2. エビデンス1枚（4分）: OECD 2026 — **AIで課題が完成しても、学びが成立したとは限らない**。AIに答えを出させた生徒は、AIを取り上げると通常より低い成績になった（[01](01_evidence.md)）。学力の定義でいえば: 生徒+AIの複合系の遂行と、**個人の内部に形成された力**は別物（[07](07_gakuryoku_definition.md)第2条項）。
3. 山場のスライド（5分）: **「校務で身につけた『出させる』うまさが、教室では最大のリスクになる」**
   - 校務の5つの慣れは全部「上手に出させる」練習だった（それでいい — 成果物の責任は教師にあるから）
   - 子どもに渡すときだけ、向きが逆になる: 失敗は2種類 — 答えを隠して守った気になると、子どもはオチを察して暗記に走る（**偽りの習熟**）。答えを与え続けると、言葉が自分の理解より先に難しくなり着地しない（**虚無**）
   - どちらもAIの制御の問題ではなく「**その時間で何をさせたいのか**」の問題 → 後半はこの向き直しの練習
4. ペアで30秒（3分）: 「自分はいまStep何? 2学期どこへ?」

## Part 3. ギャップの慣れをインストールする（15:05〜16:10 / 65分）

### ワーク6〈B6 出させない使い方〉二刀比較 — 同じ題材で「教えて」と「深めて」（15分）

自分が苦手な・説明しにくい話題を1つ決める（例: 割合、標準偏差、俳句の季語）。**同じ話題を2通りで**投げて、並べて体感する。

**①出させる版**（ふつうのGemini）:

```
◯◯がよくわかりません。中学生でもわかるように教えて。
```

**②出させない版**（配布済みの「深まる問いGem」に同じ話題を入れる）:

```
◯◯って、そもそも何なんだろう?
```

- Gemは答えない・褒めない・3行以内。「抽象度を上げた問い↑/下げた問い↓」の**二枚の扉**を返してくる → 3往復だけ潜る
- 体感の言語化（ペアで1分）: ①と②、**授業の何分後に子どもの手が止まるか**を想像して話す
- 講師のまとめ: 「①が悪いのではない。①は先生の授業準備（Step2）では正解。**子どもの探究の時間（Step4）では②に持ち替える** — これが向き直しです」
- 落とし穴: Gemの返答に「答えを教えて」と頼み込む人が必ず出る → それこそが教材。「いま皆さんがした"おねだり"を、子どもは100倍します」

### ワーク7〈B7 目的で使い分ける〉判定カード演習（10分）

6場面カード（紙）をペアで「**出させる/出させない/AIを使わない**」に仕分けて理由を言う:

1. 計算ドリルの答え合わせ → **使わない**（解答集で足りる。AIは計算を間違える）
2. 自由研究のテーマ決め → **出させない**（問いを広げる相棒に。テーマを出させたら"やらされ探究"の再生産）
3. 読書感想文の下書き → **出させない**（虚無の典型。たたき台利用は学校のねらいと規程次第=△）
4. 実験計画の穴探し（つっこみ係） → **出させてよい**（指摘という"情報"は演算の入力）
5. 調べ学習の年表整理 → **出させてよい・ただし出典裏取りとセット**
6. 苦手な子向けの類題を教師が作る → **出させてよい**（Step2の王道）

- 判定基準はスライド1枚: 「**この時間のねらいは再現か、拡張か**」「**出力は誰の成果物になるのか**」
- 正解を配ることが目的ではない — 「ペアで理由が言えたら合格。判定に迷う場面こそ職員室で話す価値がある」

### ワーク8〈B8 失敗に慣れる+B9 出典まで行く〉郷土ネタでハルシネーション・ハント（15分）

地元は先生方が専門家 — 検証できる題材でAIの限界を安全に体験する。

**手順1**: Geminiに書かせる（わざと数字を要求してエラー率を上げる）:

```
嘉手納町と周辺地域の歴史・地理・文化について、中学生向けの解説を300字で。
年号・人口などの数字を3つ以上入れて。
```

**手順2**: 出力の文に🟢🔴❓を付ける。怪しい文をGoogle検索の**AIモード**で裏取り:

```
「（AIの主張をそのまま貼る）」は本当ですか。出典つきで教えて。
```

- **出典リンクを必ず1つ開く**（要約で止まらない — 午前のコア研修と同じ作法）
- 全体で🔴の実例を2つ拾って見せる → 「これを**授業中に子どもと一緒にやる**のが『先生の失敗の授業化』です。前日に一度試しておけば（リハーサル）、教室では余裕をもってだまされられます」
- 落とし穴: 🔴が見つからない班 → 「見つからない日もあります。**🟢に根拠を付けるほうが偉い** — 検証は粗探しではなく裏取り」

### ワーク9〈B10 記録と明示〉AI利用ログを書く（5分）

A5ログ用紙（配布）に今日のワーク6〜8の利用を記録:

1. AIに何を入力したか（要約でよい）
2. 採用したもの
3. **捨てたものと、捨てた理由**（ここが核心 — 「決めたのは自分」の証拠。子どもの成果物へのAI利用明示の練習でもある）

- 「このログ用紙は2学期、子どもの探究ノートの標準装備にできます（文科省ガイドラインの『やりとりの過程の添付』の実務形）」

### OK/NGラインクイズ〈B11 手続きを確認する〉（10分）

行為カードを○×△で全員判定 → 数人に理由 → 種明かし:

| 行為 | 判定 |
|---|---|
| 学級通信の誤字チェックをAIにさせた | ○ |
| 通知表所見の素案をAIに作らせ、自分で直して確定した | ○（今日のワーク4+5そのもの） |
| AIが挙げた参考図書を、現物を確認せずに学級だよりに載せた | ×（実在確認 — 幻覚文献） |
| 子どもの作文を実名のまま貼り付けて添削させた | ×（事実メモ化・匿名化してから） |
| 読書感想文の宿題で、子どもがAIに下書きを作らせた | △（**「学校のルールとねらいを確認する」という行動が正解**。ねらいが表現の練習なら虚無化する） |
| 授業中にAIの答えが間違っていたので、その場で子どもと一緒に検証した | ◎（むしろ最良 — ワーク8の実戦形） |

- 締めの一言: 「ルールはAIを禁止するためではなく、**先生と子どもの成果物が疑われたときに守るため**にあります」
